# 처음 쓰는 사람을 위한 용어 안내

블록 라이브러리의 이름, 작업 공간의 문구·입력칸, 숫자·조건 선택 창에 마우스를 잠시 올리면 뜻과 예가 나옵니다.

| 화면의 말 | 뜻과 예 |
|---|---|
| 게임에서 카드 보여주기 | 게임 중 카드 그림을 잠깐 띄우는 연출. 카드를 만들거나 뽑는 효과는 아님 |
| 강화 후 카드 표시 | 실제로 강화한 카드를 어떤 배치로 보여줄지 설정. 잘 모르면 기본 배치 |
| 표시 시간(초) | 1은 약 1초. 그림 크기를 바꾸는 값이 아님 |
| 강화 수치 직접 적용 / 마무리 | 가져온 코드가 강화 과정을 나누어 처리할 때 사용. 보통은 일반 ‘강화’를 선택 |
| 카드에 저장한 숫자 | 카드 한 장이 기억하는 충전·사용 횟수 등. 같은 종류의 카드도 장마다 따로 저장 |
| 변수에 저장한 숫자 | 이번 블록 묶음에서 계산용으로 사용할 숫자 |
| 고른 카드 | 카드 고르기 안에서 현재 행동을 적용 중인 한 장 |
| 그 적 | 적에게 반복 안에서 현재 행동을 적용 중인 한 명 |
| 만큼 변경 | 기존 값에 더함. -1은 1 감소, 3은 3 증가 |
| 으로 설정 | 원래 값과 관계없이 입력한 숫자로 지정 |
| 파워 | 힘·취약·중독처럼 생물에게 붙는 상태 효과 |
| 중첩·스택 | 상태 효과가 쌓인 수치. 예: 중독 3 + 중독 2 = 중독 5 |
| 태그 | 특정 카드들을 찾기 위한 분류. 태그 자체가 피해 같은 행동을 만들지는 않음 |
| 키워드 | 소멸·보존처럼 카드의 기본 규칙 |
| 추가 능력(인챈트) | 카드에 별도로 붙는 게임의 추가 효과. 일반 강화와 구별 |
| 카드 풀 | 특정 캐릭터가 얻을 수 있는 카드 목록 |
| 모델 | 게임이 관리하는 실제 카드·물약·파워 등의 데이터 |
| 유형 | 카드·파워의 종류. 이미 존재하는 한 장을 지정하는 모델과 구별 |
| 출처 / 부여자 / 대상 | 효과를 만든 카드·파워 / 효과를 준 생물 / 효과를 받는 생물 |
| 영창 / 발현 | 충전 구체를 슬롯에 넣기 / 구체의 발현 효과 사용하기 |
| 발동 당시 수치 | 자원이 넘치거나 기준치에 도달한 순간의 숫자 |
| 내 블록 | 프로젝트 안에 정의한 재사용 동작. 라이브러리의 저장 묶음을 복사하는 기능과 구별 |
| DLL / PCK | 게임이 실행할 기능 파일 / 그림과 글 등의 자료 파일 |

기존 프로젝트의 효과·숫자·기간은 그대로 사용합니다. 예전 ‘크기’ 입력값도 이미 표시 시간으로 실행되던 값이므로, 이름을 바로잡은 뒤 같은 시간으로 사용됩니다.
