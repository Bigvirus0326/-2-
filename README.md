# 슬더스2 모드 메이커

슬레이 더 스파이어 2용 **카드 · 유물 · 물약 · 새 캐릭터** 모드를 화면에서 만들고,
BaseLib 기반 C# 모드 프로젝트로 내보내 빌드까지 해 주는 데스크톱 프로그램입니다.

## 실행

**배포판 (권장)**: 압축을 풀고 `StS2ModMaker.exe` 를 실행합니다. Python 이 필요 없습니다.
설정(`settings.json`)과 기본 출력 폴더(`output`)는 exe 옆에 생깁니다 (쓸 수 없는 폴더면 `%LOCALAPPDATA%\sts2_mod_maker`).
`StS2ModMaker.exe --selftest 결과.json` 으로 모든 화면·생성 기능을 보이지 않게 점검할 수 있습니다.

**소스로 실행**: `실행.bat`을 더블클릭하거나:

```
python sts2_mod_maker.py
```

기본 편집·생성에는 Python 3.9 이상이 필요하며 별도 패키지는 없습니다. 게임 화면 미리보기와 동료·전투 모습 그림 처리에는 Pillow가 필요합니다 (python -m pip install -r requirements-optional.txt). 한국어 게임 글꼴 압축 해제는 Python 3.14 이상에서 지원합니다.

## 준비물

| 항목 | 용도 | 비고 |
|---|---|---|
| .NET SDK 9 이상 | ③ 빌드 / ④ 게시 | `dotnet` 명령 |
| 슬레이 더 스파이어 2 | 게임 dll 참조, mods 폴더 | 스팀 설치 폴더 자동 탐지 |
| [BaseLib](https://github.com/Alchyr/BaseLib-StS2/releases) | 게임에서 모드를 켜려면 필요 | 게임의 `mods/` 폴더에 설치 |
| [MegaDot 4.5.1 mono](https://megadot.megacrit.com/) | ④ 게시 (그림·텍스트 .pck) | 더 새 Godot로 만든 pck는 게임이 못 읽음 |

'모드 / 빌드' 탭의 **상태 점검**에서 무엇이 빠졌는지 볼 수 있습니다.

## 사용 순서

1. **캐릭터** 탭: 새 캐릭터를 만들지 정합니다. 끄면 카드는 무색, 유물과 물약은 공용 풀에 들어가는 '콘텐츠 모드'가 됩니다.
   이름, 체력, 색, 시작 덱을 정하고, 시작 유물은 목록에서 여러 개 추가하거나 선택 삭제합니다. 애니메이션은 기존 캐릭터(아이언클래드 등)의 것을 임시로 빌려 씁니다.
2. **카드 / 유물 / 물약** 탭: '새로 만들기'로 추가하고 효과를 넣습니다. 설명은 효과에서 자동으로 만들어지고(한국어·영어·중국어 간체), 미리보기로 확인할 수 있습니다.
3. 위쪽 도구 막대에서 다음 순서로 진행합니다.
   - **① 검사**: 입력 오류 확인. 결과를 더블클릭하면 해당 편집 화면으로 이동
   - **② 생성**: 출력 폴더에 모드 프로젝트 생성
   - **③ 빌드**: `dotnet build` 실행 후 dll을 게임 `mods/모드ID/`에 복사
   - **④ 게시**: ③과 함께 MegaDot로 `.pck`(그림·현지화)를 만들어 같은 폴더에 넣음
4. 게임을 켜고 `~` 콘솔에서 `card MYMOD-STRIKE`처럼 입력하면 전투 중에 카드를 바로 얻을 수 있습니다.

프로젝트는 `파일 → 저장`으로 `.sts2mod.json` 파일에 저장됩니다.
파일 메뉴의 '프로젝트 자산 모으기…'는 참조 그림을 assets 폴더에 복사하고 상대 경로로 저장합니다.
다른 폴더에 다른 이름으로 저장한 프로젝트에 그림도 포함하려면 새 위치에서 이 기능을 다시 실행하세요.

## 지원 기능

**효과**: 피해(여러 번 타격 가능), 방어도, 카드 뽑기, 에너지, 체력 회복, 체력 잃기, 최대 체력, 골드,
파워 부여(힘, 민첩, 활력, 판금, 약화, 취약, 손상, 중독, 파멸)

**카드**: 공격/스킬/파워, 희귀도, 비용, 강화 후 비용, 대상(적 하나/모든 적/무작위 적/자신),
키워드(소멸/휘발성/선천성/보존), 강화 시 키워드 추가, 타격·수비 태그, 효과별 강화 수치

**유물**: 발동 시점(전투 시작, 매 턴 시작, 턴 종료, 카드 N장 사용마다, 전투 승리, 획득 시), 적 대상(모든 적/무작위)

**물약**: 대상(자신/적 하나/모든 적), 전투 중 사용

**캐릭터**: 체력, 색, 카드 뒷면 색(HSV), 시작 덱·유물, 아이콘·선택 화면·지도 표시 그림

## 키워드 (부여 · 제거)

- 카드 키워드는 게임의 7가지를 모두 쓸 수 있습니다: 소멸 · 휘발성 · 선천성 · 보존 · 사용불가 · 교활 · 영구.
  카드 그림에는 게임처럼 한 줄에 하나씩, 게임과 같은 순서로 나옵니다 (설명 위: 사용불가·선천성·보존·교활·휘발성 / 아래: 소멸·영구).
- 강화: **강화 시 키워드 추가** / **강화 시 키워드 제거** (예: 강화하면 소멸이 사라짐).
- 블록 코딩 '카드 조작':
  - **이 카드에 (키워드) 부여/제거** — 카드에서만.
  - **(손패 / 뽑을 카드 더미 / 버린 카드 더미 / 모든 카드 더미)의 (카드 종류) (전부 / 무작위 N장)에 (키워드) 부여/제거** —
    카드·유물·물약·파워 어디서나. 이미 그 키워드가 있는(없는) 카드는 건너뜁니다. 게임의 CardCmd.ApplyKeyword / RemoveKeyword 사용.

## 설명 자동 생성 (조건 · 변수)

- 비교 조건은 말로 씁니다: 'a가 3 이상이면 / 1 이하이면 / 6을 초과하면 / X 미만이면 / 10과 같으면 / L과 다르면'
  (영어 'is 3 or more / more than 6 / is not L', 중국어 '不少于 / 超过 / 不等于'). 숫자·영문 뒤 조사도 읽는 소리에 맞춥니다.
- 변수 블록도 설명에 들어갑니다: 'a를 3으로 정합니다', 'a에 2를 더합니다', 'a에서 1을 뺍니다' (값에서는 변수 이름 그대로).

## 에너지 X 비용 (소용돌이처럼)

- 카드 탭 키워드 줄의 **X 비용**을 켜면 남은 에너지를 전부 쓰는 카드가 됩니다 (비용 칸은 무시, 카드에 'X' 표시).
  **강화하면 X+1** 을 켜면 강화한 카드는 X 가 1 커집니다.
- X 를 쓰는 법
  - 효과 편집의 **X 사용**: 'X번 반복' (그 효과를 X번, 피해는 타격 횟수 × X) / '수치 × X'.
  - 블록 코딩 값 **X (쓴 에너지)**: 반복 횟수·조건·수치 어디에나.
- 설명은 자동으로 'X번', '3×X', 강화 시 'X+1' · '4×(X+1)' 로 만들어집니다 (한국어·영어·중국어).
- 게임에서는 게임 X 카드와 같은 방식(HasEnergyCostX + ResolveEnergyXValue)이라 화학 X 같은 X 증가 효과도 적용됩니다.

## 🤖 AI로 만들기 (ChatGPT · Claude 등 채팅 AI)

API 키나 설치 없이, 쓰고 있는 채팅 AI(무료 웹 ChatGPT·Claude·Gemini 포함)에게 카드·유물·물약·파워를 만들게 합니다.

1. 도구 막대 **🤖 AI로 만들기** (또는 메뉴 AI → ① AI에게 시키기): 만들 것을 적고 **설명서 복사**.
   설명서에는 형식, 모든 선택지(종류·희귀도·발동 시점·게임 파워·블록 코딩 명령), 지금 프로젝트의 ID 목록, 요청이 들어갑니다.
   선택지 표는 툴의 코드에서 바로 만들어지므로 툴이 바뀌어도 설명서가 같이 바뀝니다. '파일로 저장…'도 됩니다.
2. AI 채팅창에 붙여넣고 보냅니다. AI 는 ```json 코드 블록으로 답합니다.
3. AI 의 답을 통째로 복사해 **AI 결과 붙여넣기**에 넣습니다 (설명 글이 섞여 있어도 됩니다).
   - 흔한 실수는 자동으로 고치고 목록으로 보여 줍니다: 주석·끝 쉼표, 대소문자, 한국어 선택지 이름('희귀'→Rare, '취약'→Vulnerable),
     새 파워에 c: 빠뜨림, 띄어쓰기가 있는 ID 등.
   - 툴의 검사(③ 빌드 전 검사와 같은 것)를 돌려 **새로 생기는** 오류·경고만 보여 줍니다.
   - 항목마다 게임 모습 미리보기(한국어/영어/중국어, 강화)를 보여 줍니다. 더블클릭으로 넣을 항목을 고릅니다.
   - 오류가 있으면 **AI에게 보낼 수정 요청 복사** → AI 에게 붙여넣으면 고친 JSON 을 다시 줍니다.
   - 같은 ID 는 기본으로 기존 항목을 AI 버전으로 바꿉니다 (확인을 물음). '새 ID 로 추가'를 켜면 기존 것을 그대로 둡니다.
4. **프로젝트에 넣기** → 넣은 항목으로 이동합니다. Ctrl+Z 로 한 번에 되돌릴 수 있습니다.

## 카드 테두리 디자인

카드 틀 · 그림 테두리 · 제목 띠(+ 종류 명패)를 바꾼 '테두리 디자인'을 만들어 카드에 입힙니다.

- **만들기**: 캐릭터 탭 '카드 테두리' 옆 또는 카드 탭 '테두리 디자인' 옆의 '편집…'.
  부위마다 *게임 그대로* / *색 바꾸기* / *내 그림* 중 고릅니다. 오른쪽에 공격·스킬·파워 카드 3장이 실시간으로 보입니다.
- **색 바꾸기**: 색을 고르면 게임의 hsv 셰이더 값(H S V)을 정확히 계산해 넣습니다 (원본 대표색이 고른 색이 되도록).
  H S V 를 직접 고쳐도 됩니다. 카드 틀 색은 설명 칸에도 입혀지므로(게임 캐릭터 색과 같음) 너무 밝으면 글자가 안 보일 수 있습니다.
- **내 그림**: PNG 를 넣습니다. 틀·그림 테두리는 공격/스킬/파워마다 다른 그림을 쓸 수 있습니다 (비우면 '공통').
  '게임 원본 틀 PNG로 저장…'으로 원본(틀 598×844, 그림 테두리 551×420, 제목 띠 655×170)을 꺼내 그 위에 그리면 크기가 딱 맞습니다.
  그림은 ④ 게시(dll+pck)로 담아야 게임에 보입니다.
- **쓰기**: 캐릭터 탭에서 고르면 모든 카드의 기본, 카드 탭에서 카드마다 '캐릭터 기본 따르기 / 게임 원래 테두리 / 디자인' 을 고릅니다.
  여러 카드를 골라 '한꺼번에 바꾸기'로 한 번에 바꿀 수도 있습니다.
- **게임에서**: 생성되는 `<모드ID>CardFrames.cs` 가 카드 그림을 정하는 NCard 의 UpdatePortrait / Reload / UpdateTypePlaque 뒤에
  Harmony Postfix 로 붙어, 이 모드의 카드일 때만 그림·색을 바꿉니다 (다른 카드는 그대로, 고대 카드는 제외).

## 중국어 (간체)

한국어·영어를 보고 고칠 수 있는 곳에는 모두 중국어(简体中文)도 있습니다.

- **보기 전환**: 카드·유물·물약·파워 미리보기, 📖 도감, 📦 다른 모드, 캐릭터 미리보기, 🎨 전투 버튼 시험장에서 '简体中文' 을 고르면
  게임 글꼴과 게임 번역('1턴 종료' → '结束第1回合')으로 보여 줍니다.
- **입력칸**: 이름·설명(카드·유물·물약·파워), 유물 플레이버, 기믹의 태그·소환수·구체·동료 이름(영어 칸 옆 '中文'), 태그 툴팁·소환수 설명,
  전투 버튼 이름·둘째 줄·툴팁, '하나 고르기' 선택지 이름, 코드 효과 설명, 블록 편집기 설명(자동으로도 만들어짐).
- **비워 두면**: 이름은 영어 → 한국어 순으로, 설명은 효과·블록에서 중국어로 자동으로 만들어집니다.
- **게임**: 생성하면 localization/zhs 에 카드·유물·물약·파워·캐릭터뿐 아니라 동료(monsters)·구체·키워드·툴팁·고대인 대사까지 씁니다
  (캐릭터 기본 대사·고대인 대사는 중국어 원문이 없어 영어를 씁니다). 전투 버튼은 게임 언어가 중국어면 중국어 글자를 보여 줍니다.
- 다른 모드를 불러올 때 그 모드의 localization/zhs 도 읽어 중국어 이름·설명을 가져옵니다.

## 편의 기능

- **되돌리기 / 다시 실행**: Ctrl+Z / Ctrl+Y (또는 Ctrl+Shift+Z), 위쪽 도구 막대의 ↶ ↷ 버튼, '편집' 메뉴.
  입력이 잠깐(0.5초) 멈출 때마다 한 단계로 기록하고, 되돌리면 바뀐 탭·항목으로 데려갑니다. 삭제·복제·순서 바꾸기·일괄 수정·기믹·이펙트·캐릭터
  변경 모두 되돌릴 수 있습니다. 저장한 상태까지 되돌리면 제목의 * 표시가 사라집니다.
  설명 글 상자 안에서는 글 상자 자체 되돌리기가, '이펙트 그리기' 화면에서는 획 단위 되돌리기가 먼저 쓰입니다.
- **목록에서 찾기 (Ctrl+F)**: 카드·유물·물약·파워 목록 위 검색칸. 이름(한/영/중), ID, 종류, 설명으로 찾고,
  초성만 쳐도 됩니다 (ㅅㅂ → 수비). 띄어쓰기로 낱말을 나누면 모두 맞는 것만 보여 줍니다. Esc 로 지우기.
- **전체에서 찾기 (Ctrl+P)**: 카드·유물·물약·파워·태그·소환수·구체·동료·이펙트·전투 버튼을 한 번에 찾고, Enter 로 그 항목으로 갑니다.
  도구 막대 오른쪽 검색칸에 쓰고 Enter 를 눌러도 됩니다.
- **목록**: 아이콘으로 종류를 구분합니다 (카드 = 종류 색 + 희귀도 테두리 + 비용, 유물·물약 = 희귀도 색, 파워 = 버프 ▲ / 디버프 ▼).
  끌어서 순서 바꾸기, Ctrl/Shift+클릭으로 여러 개 고르기, Ctrl+A 전체 선택, Ctrl+D 복제, Delete 삭제, 오른쪽 클릭 메뉴(위로/아래로, ID 복사).
- **한꺼번에 바꾸기**: 여러 개를 고르면 목록 아래 '한꺼번에 바꾸기…' 가 나옵니다. 체크한 칸(종류·희귀도·비용·대상 등)만 고른 항목 모두에 적용합니다.

- '사용한 카드 수'는 게임의 전투 기록을 읽습니다. 지금 내고 있는 카드는 아직 세지 않습니다 (해적 모드의 '증가 전 사용 장수로 판정'과 같음).

### 직업 시스템 (디펙트 · 리젠트 · 네크로바인더처럼)

게임의 실제 시스템(구체 슬롯, 별 카운터, 골골이)을 내 캐릭터가 그대로 쓰고, 그 위에 **나만의 구체**를 만들 수 있습니다.
'예시 기믹 한 벌 추가'에 아래 예시도 들어 있습니다.

| 시스템 | 설정 | 블록 | 예시 |
|---|---|---|---|
| **구체** (디펙트) | 캐릭터 탭 → 구체 슬롯 수 · 🎲 기믹 탭 → 구체 (모양·색·아이콘, 지속/발현 수치, 지속 시점, 지속 블록·발현 블록) | 구체 영창 (기본 5종 + 새 구체), 맨 앞/맨 뒤 구체 발현, 모든 구체 지속 발동, 구체 슬롯 ±, 이 구체의 발현 수치 + (암흑처럼 자라기) · 값: 구체 수/슬롯 수/빈 슬롯, 이 구체의 지속·발현 수치 | 잉걸불: 지속 = 모든 적 피해, 발현 = 모든 적 피해 + 취약 / 흡혈: 매 턴 발현 피해가 자람 |
| **별 · 단조** (리젠트) | 캐릭터 탭 → 별 카운터 항상 표시 · 카드 탭 → 별 비용 (강화 시 ±), 별 X | 별 얻기/잃기, 단조 · 값: 별 수, X (쓴 별) | 별똥별: 별 2 비용 / 별 바라보기: 별 2 + 단조 4 / 유성우: 별 X번 모든 적 피해 |
| **골골이** (네크로바인더) | 설정 없음 | 골골이 소환 (있으면 최대 체력 증가), 골골이가 공격, 골골이 희생 · 값: 골골이 체력 · 조건: 골골이가 살아 있음 | 뼈 일으키기: 소환 5 / 뼈 찌르기: 골골이가 4 + 골골이 체력만큼 피해 |

- 밀집(Focus)이 기본 파워 목록에 추가되어 구체 수치를 올리는 카드·유물을 만들 수 있습니다.

### 파워(파워 카드)의 상시 효과로 기믹 바꾸기
★ 파워 탭 → 상시 효과 → 추가에서 고릅니다 ('무엇에'로 구체·자원·버튼을 지정, '어떤 카드에'로 종류·#태그 지정):

| 상시 효과 | 예 |
|---|---|
| 구체 수치 + (밀집처럼, 모든 구체 또는 특정 구체) · 구체 지속 효과 발동 횟수 + · 구체 슬롯 + | 잉걸불 지속 효과 2번 발동 |
| 카드 별 비용 ± (카드 필터) · 에너지가 모자라면 별로 냄 | 공격 카드 별 비용 -1 |
| 골골이 공격 피해 + · 골골이 소환량 + | 골골이 피해 +스택×2 |
| 소환수 슬롯 + | 소환 슬롯 3 → 4 |
| 자원 최대 스택 + · 카드 자원 비용 ± (자원 지정, 카드 필터) | 해룡 에너지 최대 10 → 14, 비용 -1 |
| 버튼 에너지 비용 ± · 버튼 턴당 횟수 + (특정 버튼 또는 모든 버튼) | 숨결 비용 1 → 0 |
| (기존) 주는 공격 피해 · 카드 비용 + '어떤 카드에' #태그 | 격투 카드 피해 +2 |

예시 기믹 한 벌의 파워 카드 '숙련'(파워 '기믹 숙련')에 이 상시 효과가 모두 들어 있습니다.
- 새 구체의 겉모습은 게임 구체(전기·냉기·암흑·플라즈마·유리)의 애니메이션에 색을 입혀 씁니다 (구체 애니메이션은 Spine 이라 그림 한 장으로는 만들 수 없음). 아이콘 PNG 는 툴팁·설명에 쓰입니다.
- 영창·발현·단조·소환을 쓰는 카드에는 게임의 해당 툴팁이 자동으로 붙습니다.
- 카드 미리보기(게임 화면)에 별 비용이 에너지 아래 별 아이콘으로 표시됩니다.
- 골골이의 겉모습은 게임의 네크로바인더 골골이 그대로입니다.

### 골골이형 동료 (나만의 체력 있는 소환수)
🎲 기믹 탭 → **동료 (골골이형)**. 게임의 골골이 소환(OstyCmd)과 같은 방식으로 만들어집니다:
- 처음 소환하면 전장에 체력 N 으로 서고, 살아 있을 때 또 소환하면 **최대 체력 +N**, 쓰러졌으면 **되살아납니다**.
  소환량은 게임 훅을 거치므로 상시 효과 '골골이 소환량 +'도 그대로 적용됩니다.
- '주인을 노린 공격을 대신 받음' = 게임의 DieForYou (골골이처럼 막아 줌).
- 매 턴 행동(블록): 내 턴 종료 시 / 시작 시 / 없음. 블록 안의 '나'는 동료 자신입니다.
- 블록: **동료 소환 · 동료가 공격**(앞으로 튀어 나가는 움직임) **· 동료 지금 행동 · 동료 희생**, 값 **동료 체력/최대 체력**, 조건 **동료가 살아 있음**.
- 상시 효과 **동료(골골이형) 공격 피해 +** (모든 동료 또는 특정 동료).
- 그림: PNG 한 장 + 크기 % + 띄우기 + 좌우 반전. 오른쪽에 게임 배경 위 실제 크기로 미리 보여 주고, 시험장 전투 화면에도 나옵니다.
- 예시: 동료 '도깨비불', 카드 '도깨비불 부르기'(소환 6), '불꽃 돌진'(살아 있으면 돌진, 없으면 소환).

### 캐릭터 전투 모습 바꾸기
캐릭터 탭 → **전투 모습**: PNG 한 장(크기·띄우기·좌우 반전)으로 전투 화면의 캐릭터를 바꿉니다 (BaseLib 의 그림 → 전투 모습 변환).
비우면 '임시 외형' 캐릭터의 애니메이션을 그대로 씁니다. 그림 한 장이라 걷기·공격 애니메이션은 없습니다.
이 그림은 이펙트 그리기 화면과 버튼 시험장에도 그대로 나옵니다.

## 🎨 이펙트 · 버튼 (카스토리스의 숨결 버튼·나비 이펙트처럼)

### 이펙트 그리기
- 도구: 🖌 붓(자유 선) · 직선 · 원 · 고리 · 사각형 · 다각형(점 찍고 더블클릭) · 🖼 그림(PNG). 색·굵기·불투명·채우기.
- ↖ 선택으로 도형을 골라 끌어서 옮기고, 오른쪽에서 **움직임**을 정합니다: 시작 시각, 길이, 이동, 크기(배), 회전, 끝 불투명(0이면 사라짐), 가속, **복제 수 + 퍼짐**(나비 떼·파편처럼 사방으로).
- ▶ 재생 / 반복 / 속도(1·0.5·0.25배) / 시간 막대 / '게임 빠르게 설정' 미리보기. 전투 화면 모형(나·적) 위에서 봅니다. Ctrl+Z 되돌리기.
- 미리보기와 게임은 같은 계산(위치·크기·회전·불투명 Tween)을 씁니다. 게임에서는 캐릭터 노드에 붙어 재생되고, 게임 설정이 '즉시'면 생략, '빠르게'면 2배 빠르게 재생됩니다.
- 쓰는 곳: 블록 **이펙트 재생** (나 / 대상 / 그 적 / 모든 적 / 무작위 적), 버튼의 '누를 때 이펙트'.

### 전투 버튼
- 캐릭터 옆(위치 X/Y)에 뜨는 버튼. 이름 2줄(둘째 줄의 `#` = 표시 값, 예: '피해 #'), 툴팁, 색, 크기.
- **위치 기준**
  - **화면 비율** (새 버튼 기본): 버튼 가운데를 화면의 가로 %·세로 % 에 둡니다. 크기는 기준 1920×1080 에서의 px 이고,
    게임 안에서 전투 화면 크기를 읽어 `배율 = min(너비/1920, 높이/1080)` 로 다시 계산합니다 (창 크기가 바뀔 때마다).
    → 어떤 해상도·화면 비율(16:9, 21:9, 32:9, 16:10, 4:3)에서도 같은 자리, 같은 크기.
  - **캐릭터를 따라다님**: 캐릭터 발밑 기준 px (예전 방식). 넓은 화면에서도 늘 캐릭터 머리 위에 있지만, 화면 기준 자리는 달라집니다.
  - 게임은 기준 1920×1080 + canvas_items + expand 설정이라, 넓은 모니터는 좌우가, 높은 모니터는 위아래가 더 보입니다.
    시험장의 '모니터 화면 비율'에서 고르면 게임과 같은 배치(캐릭터는 가운데, 에너지·더미는 모서리, 턴 종료는 게임처럼 화면 비율 자리)로 보여 줍니다.
- 비용·제한: 에너지 비용, 자원 비용(★ 파워), 턴당/전투당 횟수, 쓸 수 있는 조건. 못 쓰면 회색으로 잠깁니다.
- 누르면 **블록**을 실행 (카스토리스와 같은 방식: 네트워크 안전한 GameAction 으로 처리 → 멀티플레이에서도 동기화).
- 켜기: '켜는 유물'(이 유물을 가지고 전투 시작 시 자동) 또는 블록 **버튼 켜기 / 끄기**.
- **시험장 (게임 전투 화면)**: 게임 파일로 그린 실제 전투 화면 — 덩굴 숲 배경, 체력 바·방어도, 파워 아이콘, 적 의도,
  캐릭터별 에너지 구슬, 별 카운터, 턴 종료 버튼, 손패(내 카드 실제 합성), 게임 글꼴의 버튼과 설명 말풍선.
  버튼을 누르면 블록이 실제로 계산되어 적 체력·방어도·에너지·별·자원이 바뀌고 피해 숫자와 이펙트가 뜹니다.
  '이번 턴 사용한 카드'·별·자원을 바꿔 조건과 표시 값(#)을 시험하고, '턴 넘기기'(적 공격·에너지 회복), '전투 다시', 한국어/English, Ctrl+끌기로 위치 옮기기.
  캐릭터·몬스터 몸은 게임에서 Spine 애니메이션이라 실루엣으로 대신합니다. 계산하지 못하는 블록(소환·구체 등)은 기록에 '생략'으로 표시됩니다.
- 이펙트 그리기 화면도 게임 배경(캐릭터 주변) 위에서 그리고 재생합니다.

### 게임 안에서 시험
빌드한 모드에는 개발자 콘솔 명령이 들어갑니다 (모드 ID 소문자 + fx/btn):
- `<모드id>fx 이펙트id` — 내 캐릭터에서 재생, `<모드id>fx 이펙트id enemy` — 첫 번째 적에서 재생
- `<모드id>btn 버튼id` — 버튼 켜기, `<모드id>btn 버튼id off` — 끄기

예시 기믹 한 벌에 '나비 폭발'·'달빛 베기' 이펙트와 '숨결' 버튼(에너지 1, 턴당 1번, 모든 적 피해)이 들어 있습니다.

## 생성되는 프로젝트

[Alchyr/ModTemplate-StS2](https://github.com/Alchyr/ModTemplate-StS2)의 캐릭터 템플릿 구조를 따릅니다.

```
출력폴더/모드ID/
├─ 모드ID.csproj, 모드ID.json(모드 정보), project.godot, export_presets.cfg
├─ 모드ID/                ← Godot 리소스 (pck에 들어감)
│  ├─ images/card_portraits, relics, potions, charui
│  └─ localization/kor, eng
└─ 모드ID Code/
   ├─ Cards/, Relics/, Potions/, Character/   ← 생성된 C#
   └─ MainFile.cs
```

생성된 C# 파일은 직접 고쳐서 더 복잡한 효과를 넣어도 됩니다. 단, 첫 줄에 '모드 메이커가 생성' 표시가 있는 파일은
다시 생성할 때 덮어쓰므로, 직접 만든 코드는 새 파일로 두는 것이 안전합니다.
